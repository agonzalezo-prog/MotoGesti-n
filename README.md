# 🏍️Aplicativo Web para la Gestión de Procesos en un Taller de Motocicletas “MotoGestión”🏍️

## Descripción General

Este proyecto consiste en una aplicación web desarrollada para la gestión y seguimiento de motocicletas dentro de un taller.

El sistema permite registrar clientes y motocicletas, realizar seguimiento al proceso de reparación, administrar repuestos y servicios, generar facturas y consultar historiales de facturación.

Su principal objetivo es brindar una herramienta que facilite la organización del taller y permita al cliente conocer el estado actual de su motocicleta durante todo el proceso de reparación.

---

## Objetivo

Desarrollar una solución web que permita controlar de manera organizada las actividades de un taller de motos, mejorando la gestión de la información y la comunicación con los clientes.

---

## Funcionalidades

### Dashboard
- Visualización de estadísticas generales.
- Control de motos ingresadas.
- Alertas de retrasos.
- Seguimiento de órdenes activas.

### Registro de Ingreso
- Registro de clientes.
- Registro de motocicletas.
- Generación automática de órdenes.

### Gestión de Procesos
- Actualización de estados.
- Bitácora de actividades.
- Registro de repuestos.
- Registro de servicios.

### Facturación
- Cálculo automático de costos.
- Generación de facturas.
- Registro de métodos de pago.

### Historial
- Consulta de facturas.
- Búsqueda por cliente.
- Búsqueda por placa.
- Impresión de facturas.

## Instrucciones de Ejecución

### Requisitos

- Navegador web actualizado.
- Visual Studio Code (opcional para edición).

### Pasos para ejecutar

1. Descargar o clonar el repositorio.

git clone https://github.com/agonzalezo-prog/MotoGesti-n
```

2. Abrir la carpeta del proyecto.

3. Ubicar el archivo:

index.html
```

4. Abrir el archivo en el navegador.

También puede ejecutarse utilizando la extensión:

**Live Server** de Visual Studio Code.

### Ejecutar con Live Server

1. Instalar la extensión Live Server.
2. Abrir el proyecto.
3. Hacer clic derecho sobre:

index.html
```

4. Seleccionar:

Open with Live Server
```

5. El sistema abrirá automáticamente en el navegador.

## Almacenamiento de Datos

La aplicación utiliza LocalStorage para almacenar la información.

Esto significa que:

- Los datos quedan guardados en el navegador.
- No requiere base de datos.
- La información permanece disponible aunque se cierre la página.
